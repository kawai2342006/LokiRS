# Loki Archive — LokiRS 實作規格

來源：使用者提供的 TVA 財經日報參考圖與 `loki_style_prompt.md`。原始規格保存於 `LOKI_STYLE_REFERENCE.md`。

## 色彩與字體

| 用途 | 色值 |
| --- | --- |
| 主背景／深層／最深層 | `#091b14` / `#07130f` / `#030a07` |
| 主要文字／輔助文字 | `#f0e6cb` / `#a5b1a1` |
| 黃銅結構／檔案標籤 | `#cdb477` / `#dba15d` |
| 正面數據／負面數據 | `#8ddd9b` / `#f18a73` |
| 主線／細線 | `rgba(205,180,119,.31)` / `rgba(205,180,119,.16)` |

標題：Noto Serif TC 700–900。正文：Noto Sans TC 400–700。數據／代號：IBM Plex Mono 400–600 + tabular-nums。

字體存於 `assets/fonts/`，附三個 OFL 授權檔。中文字體保留目前 UI／板塊用字子集，其他新增字元由 CSS 系統備用字體顯示。新增大量文字時可更新字體子集。

## 從報紙延伸至儀表板

參考稿 600px 是報紙輸出尺寸；LokiRS 採響應式寬版，保留銅框、雙線、字距、襯線標題、等寬數字及紙紋比例，讓多欄排名表可以閱讀。外框上限 1536px，手機逐段改為單欄，資料表保留獨立橫向捲動，不以縮小所有文字塞入。

結構與控制元件採硬直角。圓形只用於印章、儀表弧線與圖表數據點。裝飾 SVG 使用中性黃銅色，正負色保留給數值、動能走勢及情緒指標。

## 元件對應

| 參考元素 | LokiRS 實作 |
| --- | --- |
| 頁頂檔案列 | `archive-line`，行情日期由 JSON 更新 |
| 皇冠線稿 | 原創幾何 SVG `assets/crown.svg` |
| 雙線報頭 | `site-header` 的黃銅 double border |
| 圓形印章 | `seal`，內圈虛線、旋轉 −9° |
| 銅底頁籤 | `file-tab`，隨排名／自選／比較切換 |
| 章節檔案號 | `section-number` / `panel-code` |
| 時間線裝飾 | `timeline-rule`，純裝飾，不表示價格資料 |
| 條紋研究備註 | `notice`，銅色邊框及分欄標籤 |
| 卡片角標 | `panel::after`，不覆蓋正文 |
| 頁腳代號 | `archive-footer` |

## 互動與相容性

- 預設 `data-theme="dark"` 為檔案紙紋；`reading` 為純色閱讀。
- 舊 `light` 設定轉為閱讀模式。舊自選與比較資料由 `openrs:` 向後相容讀取；新版寫入 `lokirs:`。
- 比較線僅用黃銅／紙白／橙／灰綠及不同線型表示資產身份。綠／珊瑚代表正負變化。
- CSV 檔名改為 `lokirs-日期.csv`，分數欄名稱為 `LokiRS_approx`。SVG 檔名改為 `lokirs-comparison-日期.svg`。
- JSON 欄位、原公式、快取路徑與 Python 抓價程式維持相容。

後續修改時，先遵守色彩語義、字體分工及數據對齊；新增欄位應延伸現有銅色結構，不加入螢光品牌色或圓角卡片。
