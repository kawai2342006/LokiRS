# LokiRS v1.3 — 美股五時段公式校準

已按 2026-10-30、2026-11-02 兩個美股收市快照校準 01 美股排名，並用 Yahoo 獨立行情重算。這份更新包未推送或部署到 GitHub。

## 安裝

1. 解壓縮 `LokiRS_Calibration_Update.zip`，將內容覆蓋上傳到現有 LokiRS 倉庫根目錄，不要再包一層資料夾。
2. 必須一併更新 `config/settings.json`、`scripts/`、`assets/app.js`、`index.html` 及 `data/latest.json`，以免設定、計算與畫面使用不同版本。
3. 沿用現有 Pages 發佈方式，完成後重新整理。`preview/LokiRS_Calibration_Preview.html` 可直接開啟作離線檢視，不需要發佈。

此包附帶 **2026-11-02** 股票快照；若你上傳時倉庫已有更新日期，應先用新版程式重新抓價，再發佈，避免倒退行情日期。股票池仍保留你現有的 589 隻，沒有自動加入原站新增股票。主頁行情、自選儲存、長線 RS 權重及情緒來源設定沿用原有版本。

## 新公式

```text
LokiRS = 0.25 × 1H 超額
       + 0.25 × 4H 超額
       + 0.25 × 1D 超額
       + 0.15 × 5D 超額
       + 0.10 × 20D 超額
```

超額均相對 SPY。1H／4H 指常規交易時段的 K 線格數；標準收市最後一根只有半小時，因此收市跨度是 0.5／3.5 個時鐘小時。5D／20D 是交易日，與表格「一週／一個月」曆日欄不同。

權重由公開數據估算，並非原站官方確認。以兩日共 1,180 筆原站公開輸入核對時，分數最大誤差低於 0.0001；改用獨立 Yahoo 報價後仍有小量差距。完整方法及結果見 [docs/CALIBRATION.md](docs/CALIBRATION.md)。

## 更新與核對

只更新美股及板塊排名：

```bash
python3 scripts/update_data.py --rankings-only
```

沿用完整更新流程：

```bash
python3 scripts/update_data.py
```

與當日原站公開預設排名比較：

```bash
python3 scripts/compare_rankings.py --output comparison.json
```

比較程式要求觀測日期相同，按共同股票重新編排名，並報告不在共同股票池的代號。它讀取公開頁面已有的免費排名資料，只作診斷，不會把原站分數當作 LokiRS 的行情來源。

日線仍使用兩年 Yahoo 歷史；30 分鐘線改取最近 58 個曆日，以同一五時段公式重算過往名次、Δ、板塊排名、vs 板塊及持續日數。缺少同步 1H／4H 或日線輸入時不排名。小時線歷史有限，`40+` 等標示代表至少持續該日數，不會用舊日線公式補齊較早紀錄。

若你採用更新包內的 GitHub Actions 工作流程，請完整上傳 `.github/` 資料夾並將 Pages 來源設為 GitHub Actions；分支式 Pages 可保留原設定，在本機執行更新後提交 `data/`。工作流程未在遠端執行驗證。
