# LokiRS · Loki Archive 主題更新

## 如何更新現有 GitHub 網站

1. 解壓 `LokiRS_Theme_Update.zip`。
2. 將壓縮檔內的檔案與資料夾上傳到 `kawai2342006/LokiRS` 的根目錄，覆蓋同名檔案。上傳後根目錄應直接看到 `index.html`，不要多包一層資料夾。
3. `assets/` 必須完整上傳，包括 `assets/fonts/`；只換 CSS 會缺少皇冠與字體。
4. 提交後沿用現有 GitHub Pages 發佈流程。發佈完成可用 Ctrl+Shift+R／Cmd+Shift+R 重新整理。

主題包不含行情、股票池或計算程式，不會覆蓋較新的行情。沒有修改帳戶設定、部署流程或更新排程；也沒有把任何更改推送到 GitHub。

## 本次內容

- LokiRS 名稱、皇冠 SVG、TVA 檔案列、檔案編號、圓形印章、時間線線稿及銅色文件框。
- 黑松綠紙紋、舊黃銅結構線、暖紙白文字；正負數據使用指定綠／珊瑚色。
- Noto Serif TC 標題、Noto Sans TC 正文、IBM Plex Mono 數據；字體自託管，附授權。
- 排名、篩選器、市場概況、Top 10、比較圖、彈出視窗及匯出圖表統一主題。
- 比較圖以四種中性色加實線／虛線／點線區分資產，正負變化仍採語義色。
- 桌面寬版與手機單欄；排名表保留橫向捲動，資產欄固定方便對照。
- 「閱讀模式」移除紙紋，仍使用深綠與黃銅色；不使用原本的白底淺色模式。

## 自選清單及比較名單

在同一網址、同一瀏覽器更新時，新版會先讀取 `lokirs:` 設定；未有新版設定時，會讀取舊 `openrs:` 設定。舊資料不會刪除，新設定寫入 `lokirs:`。因此既有自選與比較名單可以延續。

資料只存在個別裝置與瀏覽器，不能跨裝置同步。離線預覽使用獨立儲存位置，不會更動線上網站的名單。

## 預覽與驗證限制

`LokiRS_Preview.html` 是同一主題的獨立離線展示，內含 2026-10-30 真實行情快照與字體，可直接以瀏覽器開啟。它不會重新抓價；正式網站繼續讀取 `data/latest.json`。

20 項模擬 DOM 互動檢查通過，原有 15 項 Python 計算測試、3 項圖表測試與靜態建置通過。資料、股票池、公式及抓價程式與 GitHub 基準版本一致。

本次執行環境的預覽服務無法啟動，因此實際瀏覽器／手機的字體、尺寸、捲動與視覺排版仍待人工驗收。完整記錄見 `docs/LOKI_THEME_VALIDATION.md`。
