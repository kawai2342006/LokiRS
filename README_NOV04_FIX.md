# LokiRS v1.3.1 — 日期、發佈及 11 月 4 日核對

這份更新修正更新工作流程的日期一致性錯誤，並覆核 2026-11-04 公開排名。美股五時段權重保持 25%／25%／25%／15%／10%（1H／4H／1D／5D／20D）；沒有為新一日重新調權重。

## 已確認的失敗原因

執行紀錄 `41953388196` 的抓價、保存快照均成功，但 **Build static files** 驗證失敗。當時 SPY 的有效日線只到 11 月 3 日，個別股票 SOMN 已有 11 月 4 日；舊程式計算 11 月 3 日分數時，卻顯示 SOMN 的 11 月 4 日價格及日期，遭一致性驗證拒絕。網站因此保留較早已部署版本。

這次保留驗證，修正價格／日期與排名基準的對齊。檢查時間亦未見當日 `schedule` 事件執行紀錄；不能由公開紀錄確定未觸發的原因。06:17 是排程要求時間，不是更新完成保證。

## 修正內容

- 價格及資料日期與同一 SPY 交易日對齊，不把較新股票價格配上較舊排名。
- 日線請求使用明確起訖時間並記錄下載時點；跨過收市時不沿用盤中快取，也不會把盤中保存的未完成 K 線隨時間推移當成收市。
- 新日線有缺值時，整批下載後先重試一次。只有同日常規時段全部 30 分鐘 K 線已完成、價格調整資料已核對、期間沒有股息／拆股／資本分派事件，且前一有效日的調整比例為 1，才可用實際小時線收市價重建最新一天。重建值有來源標記；原日線可用時優先採用原值。其他缺值保留缺值。
- 股票及主頁共用已核對的美股基準日，防止主頁另讀落後的 SPY 日線。
- 新股票快照先驗證才寫出；工作流程先建置成功，才將快照提交到倉庫。
- 保留香港時間星期二至六 **06:17** 主排程，另加 **08:17** 補跑，亦讓 UTC 日線市場有時間完成收市。GitHub 排程可能延遲或漏跑，補跑不能保證準點。

## 安裝

1. 將更新包內容覆蓋到現有 LokiRS 倉庫根目錄，保留資料夾結構。
2. 必須包含更新後的 `.github/workflows/pages.yml`、`scripts/`、`assets/`、`index.html`、`config/settings.json` 及兩個行情 JSON。
3. GitHub Pages 來源維持 **GitHub Actions**。提交到 main 後，會啟動新的更新及部署流程；也可在 Actions → Update data and deploy Pages → Run workflow，選 main 並保留 refresh_data 勾選。
4. 等 prepare 與 deploy 都成功，再到網站按 Refresh。舊執行的 Re-run all jobs 仍使用舊版本；應開新一次 Run workflow。
