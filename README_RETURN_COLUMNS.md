# 3D／兩周超額更新（v1.4.1）

## 「超額」的意思

此說明適用於美股排名頁。超額 = 個股同期回報 − SPY 同期回報，單位為百分點（pp）。個股升 5%、SPY 升 2%，超額就是 +3 pp；個股跌 1%、SPY 跌 4%，超額亦是 +3 pp，代表相對跑贏。日線使用原程式的股息及拆股調整價格。

| 欄位 | 起點與計法 |
| --- | --- |
| 1H／4H | 1／4 根完成的小時 K 線；原程式以 30 分鐘線重建，標準收市末根只有半小時，所以收市時跨度為 0.5／3.5 小時 |
| 1D | 前 1 個 SPY 交易日收市至本期收市 |
| **3D（新增）** | 前 **3 個 SPY 交易日**收市至本期收市；按起訖價格算累計回報，再減 SPY 回報，不是相加每日超額 |
| 一週 | 本期日期減 **7 個曆日** |
| **兩周（新增）** | 本期日期減 **14 個曆日**，沿用原有週期定義 |
| 一個月 | 前一個曆月同日，月底會截到有效日期 |

曆日週期的目標日如沒有 SPY 交易，取目標日或之前最近的 SPY 交易日。個股必須有同一起訖日期；缺值留空，不取個股較舊價格補位。現有一週不一定等於分數公式中的 5D，一個月亦不一定等於 20D。

主頁跨市場表的基準是當期有效資產回報中位數；與美股頁的 SPY 基準不同。本次修改美股及其自選清單。

## 「長線」的意思

先計算：

```text
長線值 = 40% × 超額 63 個交易日
       + 20% × 超額 126 個交易日
       + 20% × 超額 189 個交易日
       + 20% × 超額 252 個交易日
```

四段約為 3／6／9／12 個月，全部相對 SPY。再將長線值放在本期資料有效的股票池中，轉為 0–100 百分位：越高表示長期相對表現越強。80 大致代表強過八成有效股票，不代表回報 80%，亦不是超額 80 pp；同值取平均名次，缺少所需起訖日資料留空。

這是現有程式的公開近似公式，並非原參考站官方確認的長線公式。

## 修改內容

- 排名欄位順序：1D → **3D** → 一週 → **兩周** → 一個月。
- 兩欄可排序、作數值篩選、在自選清單顯示；缺值排在最後及不通過數值篩選。
- 個股詳情包含新數值及實際起訖日；表格 hover 可查看日期。
- CSV 新增 `3d_excess_pp`、`fortnight_excess_pp`、`3d_from`、`fortnight_from`。
- 美股超額顯示改用 `pp`，SPY 本身的股價升跌仍使用 `%`。
- `scripts/engine.py` 的後續正常抓價會自動計算兩欄；原有分數權重及長線算法沿用。
- `scripts/add_return_columns.py` 可為保留歷史價格的舊快照補欄，毋須下載行情或重排名。

附件的 596 隻股票已全部補齊。快照仍是 **2026-11-09 收市**：3D 起點是 2026-11-04，兩周起點是 2026-10-26。補欄使用原快照內已儲存至四個小數位的調整價格；正常更新會用資料供應者的完整精度，因此最低小數位可能略有差異。逐項比較確認原快照的所有既有值及日期完全保留。
