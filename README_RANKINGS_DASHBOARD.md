# LokiRS 1.5.0 — 美股排名與篩選 Dashboard

本更新沿用原有 GitHub Pages 架構、股票池、價格、計分公式及排名。

## 本次更新

1. 排名列表移除資產左側星號。點股票代號後，在詳情視窗左上角、ticker 右方按 ☆／★ 加入或移除「02 自選清單」。沿用已儲存的自選記錄。
2. 預設排序標題為「LokiRS ↓」，副標題為「綜合分數」，仍可點欄名切換排序。
3. 網頁及新 CSV 超額欄改用 %；公式及數值不變，仍是個股與 SPY 回報的百分點差。例如個股 +5%、SPY +2%，超額顯示 +3%。
4. 新增可排序的 USD 市值欄，同時列於個股詳情及 CSV。K／M／B 分別代表千／百萬／十億；一萬億顯示 1,000.00B。
5. 右方數值篩選新增「市值 USD」，可選 ≥／≤、數值及 K／M／B。例如「市值 USD ≥ 10 B」代表至少 100 億美元。
6. 篩選面板下方新增可收起的「篩選結果 Dashboard」。
7. 刪除整行「研究備註／FIELD NOTE／公開數據，透明計算。」橫幅，計算方法仍可由頁尾開啟。

## Dashboard 圖表及指標

| 顯示 | 用途／計算 |
| --- | --- |
| 板塊股票數量長條及佔比 | 比較 37 個現有分類的股票數量，完整分類可捲動查看 |
| 板塊強弱熱圖 | 各板塊內篩選股票的 LokiRS、1D、一週及一月超額中位數；各股等權，減少極端值影響 |
| 板塊 1D 跑贏比例 | 該板塊 1D 超額 > 0 的數量／有 1D 數據的數量 |

| 各時段跑贏 SPY 比例 | 1H／4H／1D／3D／一週／兩周／一月，各時段使用自己的有效分母 |
| 四個摘要指標 | 綜合分數中位數、1D 跑贏比例、長線 RS ≥ 50 比例、持續 ≥ 7 日比例 |

搜尋、板塊、首 3／5 板塊、所有數值及快速篩選、重設、新快照載入均共用同一份結果。Dashboard 與 CSV 使用完整篩選清單，分頁只影響排名表格。點熱圖內的板塊名稱可套用板塊篩選。熱圖不是板塊 ETF 回報。

## 市值來源與時點

市值取自 Nasdaq 公開 Stock Screener，獨立於原有 Yahoo 價格；沒有用價格推算市值。更新流程已加入抓取及六小時快取；Nasdaq 的 BRK/B 會對應 BRK-B。

目前覆蓋 594／596 隻股票；BF-B、ET 缺值，顯示「—」，市值篩選時排除。來源失敗或部分缺值時，已有市值保留原數值、日期及來源，並標為「舊值」；沒有歷史值者維持缺值，不影響排名發布。

來源未提供市值觀察日期時，只顯示實際抓取時間（HKT），不聲稱為同日收市市值。個股詳情、欄位提示及 CSV 會顯示來源、時間及狀態。

CSV 新增 `market_cap_USD` 等欄位；超額欄名由 `_pp` 改為 `_pct`，分數欄由 `LokiRS_approx` 改為 `LokiRS_score`。若另有程式讀取舊欄名，請同步調整。

## 預覽與部署

- 直接開啟 `preview/LokiRS_Rankings_Dashboard_Preview.html`，會進入美股排名。字型、程式及快照均已內嵌；行情固定於 2026-11-09，不會更新網上行情。預覽自選記錄與正式網站分開。
- 在原本 GitHub 儲存庫覆蓋本包內容並 commit／push，沿用 `.github/workflows/pages.yml` 部署。請包含新增的 `assets/rankings.js` 及 `scripts/market_caps.py`。
- 如只部署本包快照，可在 Run workflow 取消勾選 `refresh_data`；勾選會更新行情及市值。
- 重建離線預覽：`python scripts/build_preview.py --stocks`。

此更新包本身不會變更已部署的 GitHub Pages 網站。

## 驗證
